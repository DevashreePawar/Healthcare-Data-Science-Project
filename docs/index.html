Key Findings

  • RQ1: HbA1c increases 0.1-0.15% per hospitalization - disease progression evident
  • RQ2: Competing risks (mortality) must be accounted for in prognosis - Aalen-Johansen method essential
  • RQ3: XGBoost + SMOTE achieves 87% ROC-AUC with 82% sensitivity for readmission prediction

Run It Locally

Don't want to use the web version? Run the dashboard on your own machine:

1. Install R packages:

install.packages(c(
  "shiny", "shinydashboard", "tidyverse", "plotly", "DT",
  "lme4", "lmerTest", "cmprsk", "tidymodels", "DALEXtra",
  "RColorBrewer", "janitor", "forcats"
))

2. Clone and run:

git clone https://github.com/DevashreePawar/Healthcare-Data-Science-Project.git
cd Healthcare-Data-Science-Project
Rscript -e "shiny::runApp('app.R')"

The dashboard will open at http://127.0.0.1:xxxx

About This Analysis

This project combines longitudinal statistical modeling with machine learning to analyze diabetes progression. It explores three research questions:

  • How does glycemic control evolve over repeated hospitalizations? (Linear Mixed-Effects Model)
  • What is the cumulative incidence of major complications accounting for competing risk of death? (Aalen-Johansen)
  • Can we predict readmission at the next visit? (XGBoost with SMOTE)

Dataset: Diabetes 130-US Hospitals (UCI ML Repository) - 101,766 encounters, 71,490 patients, 55,453 with ≥2 visits
